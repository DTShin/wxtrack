# 气象预报追踪系统 — 运行手册

## 项目概述

长期追踪全球 48 个机场城市的每日最高气温，对比 13 个气象模型的预报值与 METAR 实测值，统计偏差并通过滚动修正提升预测准确度。

## 定时任务（4 个）

| 时间(北京) | 任务 | 内容 |
|---|---|---|
| 08:30/12:30/16:30/20:30/00:30/04:30 | 预报采集+综合研判 | Open-Meteo(12模型) + meteoblue → predict.py → 腾讯文档 |
| 19:05 | 实测采集 | METAR T+1 采集昨日实测最高温 |
| 19:20 | 统计+同步+知识库 | bias统计 → sync准备 → vault重建 |
| 20:00 | 健康检查 | 数据量验证、模型覆盖、异常告警 |

## 命令行用法

### 预报采集（每日 6 次定时执行）

```bash
cd /workspace
python3 scripts/collect_forecast.py [--slot auto] [--cities ZBAA,RJTT] [--skip-meteoblue]
```

- `--slot auto`：自动归并到「按小时」采集槽（`YYYY-MM-DDTHH:30Z`），每小时一个独立永久版本
- `--skip-meteoblue`：跳过 meteoblue 网页抓取（加速）

### 实测采集（每日 1 次，11:05 UTC）

```bash
python3 scripts/collect_obs.py [--date 2026-07-22] [--skip-wu]
```

- `--date`：指定目标日期，默认自动推断（亚欧澳→当日，美洲→昨日）
- WU 抓取当前因沙箱 IP 封锁不可用，`--skip-wu` 已是默认行为

### 偏差统计

```bash
python3 scripts/stats_bias.py [--window 30] [--out data/exports/bias.xlsx]
```

### 知识库生成

```bash
python3 scripts/gen_vault.py [--date 2026-07-22]
```

### 腾讯文档同步（需 Agent 环境执行 MCP 操作）

```bash
# 准备数据
python3 scripts/sync_smartsheet.py --prepare --date 2026-07-22
# Agent 读取 data/exports/smartsheet_T1.json 后调用 MCP add_records
```

## 数据模型

### forecast_snapshot（预报快照，全版本保留）

| 字段 | 说明 |
|---|---|
| city | ICAO 代码 |
| model | 模型 ID |
| target_date | 目标本地日 (YYYY-MM-DD) |
| lead_days | 提前天数 (0=D0, 1=D+1...) |
| tmax | 预报最高温 °C，NULL=无数据 |
| run_slot | 采集批次 (e.g. 2026-07-22T08:30Z) |
| collected_at | UTC 采集时刻 |
| source | open-meteo / meteoblue |

### obs_tmax（实测记录）

| 字段 | 说明 |
|---|---|
| city / local_date | 联合主键 |
| tmax_metar | METAR 推算最高温 |
| tmax_wu | WU 抓取值（当前不可用） |
| tmax_final | 采用值 |
| src_final | metar / wu |
| conflict | 双源冲突标记 |
| revised | 次日复核修正标记 |

### bias_stat（偏差统计）

| 字段 | 说明 |
|---|---|
| stat_date / city / model / lead_days / window_days | 联合主键 |
| n / bias / mae / rmse | 统计指标 |

## 补跑方法

- 漏跑预报：`python3 scripts/collect_forecast.py --slot 2026-07-22T08:30Z`（指定具体 slot，UNIQUE 幂等）
- 漏跑实测：`python3 scripts/collect_obs.py --date 2026-07-22`（指定日期）
- 仅某城市：`--cities ZBAA,RJTT`

## 降级策略

| 场景 | 处理 |
|---|---|
| meteoblue 改版 | 解析失败记 N/A，不影响主流程 |
| Open-Meteo model id 变更 | 响应 error 自动记 N/A，修改 models.yaml 即可 |
| METAR 缺报 | hours 窗扩至 48；仍缺→当日该城缺测 |
| WU 反爬/IP封锁 | 当前沙箱 IP 已被封锁，仅用 METAR |
| smartsheet 限流 | 指数退避重试；失败落本地队列次日补 |
| 夏令时切换 | 全 IANA tz + UTC 存储，自动处理 |
